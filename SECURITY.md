# Политика безопасности OnlineSeti VPN

## Поддерживаемые версии

Исправления безопасности выпускаются для последней опубликованной стабильной версии Android-приложения. Предварительные, тестовые и самостоятельно собранные версии могут не получать исправления; после публикации обновления установите его как можно скорее.

| Версия | Поддержка |
| --- | --- |
| Последняя стабильная версия из [релизов](https://github.com/dennt86/OnlineSeti/releases) | Поддерживается |
| Более старые версии, beta/dev и тестовые сборки | Не поддерживаются |

## Как сообщить об уязвимости

Пожалуйста, **не публикуйте сведения об уязвимости, рабочий эксплойт или чувствительные данные в публичном GitHub Issue**.

Отправьте описание на **dennt86@mail.ru** с темой `Security report — OnlineSeti VPN`. Если в GitHub на странице Security доступна кнопка **Report a vulnerability**, можно воспользоваться приватным сообщением вместо электронной почты.

Укажите, если это безопасно:

- затронутую версию приложения и модель устройства/версию Android;
- краткое описание проблемы, её возможные последствия и шаги воспроизведения;
- минимальный безопасный пример или материалы, которые помогут проверить проблему.

Не включайте в сообщение пароли, ключи, токены подписки, личные данные других пользователей или действующие реквизиты серверов. Если для демонстрации нужны такие данные, замените их тестовыми значениями.

Мы рассмотрим сообщение и при необходимости свяжемся для уточнений. Пожалуйста, дайте время на проверку и выпуск исправления; публичное раскрытие согласуйте заранее. Срок ответа или вознаграждение за сообщение не гарантируются.

## Область действия

Политика относится к Android-приложению OnlineSeti VPN и к коду этого репозитория. Для уязвимости в стороннем компоненте, ядре или сервисе также сообщите соответствующим разработчикам; не публикуйте секреты конфигураций OnlineSeti.

# OnlineSeti VPN Security Policy

## Supported versions

Security fixes are provided for the latest published stable Android app release. Preview, test, and self-built versions may not receive fixes. Install updates promptly after they are published.

| Version | Support |
| --- | --- |
| Latest stable version listed in [Releases](https://github.com/dennt86/OnlineSeti/releases) | Supported |
| Older versions, beta/dev, and test builds | Unsupported |

## Reporting a vulnerability

**Do not disclose vulnerabilities, working exploits, or sensitive information in a public GitHub issue.**

Email **dennt86@mail.ru** with the subject `Security report — OnlineSeti VPN`. If GitHub offers **Report a vulnerability** on this repository's Security page, you may use that private channel instead.

When safe to do so, include the affected app version and device/Android version, a concise description of the impact, reproduction steps, and a minimal safe proof of concept. Do not include passwords, keys, subscription tokens, other users' personal data, or live server credentials; replace them with test values.

Reports will be reviewed and we may request more information. Please allow time to investigate and prepare a fix, and coordinate public disclosure with us in advance. A response time or bounty is not guaranteed.

## Scope

This policy covers the OnlineSeti VPN Android app and code in this repository. For issues in a third-party component, core, or service, also notify its maintainers. Never publish OnlineSeti configuration secrets.
