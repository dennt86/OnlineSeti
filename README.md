# Onlineseti VPN

Тестовое Android-приложение на основе [qThroneMobile](https://github.com/ttrroyy/qThroneMobile).

APK и архив исходников приложения и ядра доступны в разделе Releases. Для современных телефонов выбирайте arm64-v8a.

Версия 0.1.0: оформление Onlineseti, импорт подписки, автоматический выбор соединения. Сборка и модульные тесты прошли; работа на телефоне и переключение при обрыве требуют проверки. Это debug-сборка для тестирования.
