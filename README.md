# OnlineSeti VPN для Android

Фирменная Android-сборка OnlineSeti VPN: подписки, автоматический выбор доступного сервера, маршрутизация российских сервисов напрямую и поддержка протоколов sing-box/Xray и дополнительных транспортов.

## Установка и использование

1. Скачайте APK только из раздела [Releases](https://github.com/dennt86/OnlineSeti/releases).
2. Установите приложение и откройте его.
3. Добавьте подписку OnlineSeti из Telegram-бота или вставьте ссылку вручную.
4. Разрешите Android создать VPN-подключение и нажмите «Подключить».
5. Если связь пропала, обновите подписку и откройте раздел серверов: приложение покажет результаты проверки и текущий выбранный узел.

Поддержка и получение подписки: [openseti.ru](https://openseti.ru).

## Сборка и проверка

Проект собирает Android APK из исходников с закреплёнными версиями upstream-ядер и нативных транспортов. CI запускает unit-тесты, проверки маршрутизации, security-regression тесты и сборку APK. Локальная инструкция находится в [README-ONLINESETI.md](README-ONLINESETI.md).

Перед массовым распространением конкретный APK нужно проверить на реальных телефонах, сетях Wi-Fi/мобильной связи, подписках и сценариях восстановления/обновления. Debug APK — только для проверки; для установки поверх предыдущего релиза необходима подпись тем же постоянным ключом.

Клиент создан на основе [qThroneMobile](https://github.com/ttrroyy/qThroneMobile) и использует компоненты sing-box, Xray и сторонние транспортные клиенты. Подробности и закреплённые версии перечислены в [README-ONLINESETI.md](README-ONLINESETI.md), каталоге `app/src/main/assets/carrier-licenses` и файле `LICENSE`.
