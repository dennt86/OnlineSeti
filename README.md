# Onlineseti VPN

Android VPN-клиент с автоматическим выбором соединения и маршрутизацией российских сервисов напрямую.

**Последняя тестовая версия: 0.1.2.** APK для Android и архив исходников опубликованы в [релизе v0.1.2](https://github.com/dennt86/OnlineSeti/releases/tag/v0.1.2). Для большинства современных телефонов выбирайте `arm64-v8a`.

Это предварительная debug-сборка для тестирования. Проверяйте SHA-256 по файлу `SHA256SUMS` в релизе. Минимальная версия Android — 7.0.

Приложение создано на основе открытого проекта [qThroneMobile](https://github.com/ttrroyy/qThroneMobile); исходные лицензии и уведомления сохранены в архиве исходников. Вопросы и предложения — через Issues этого репозитория.
