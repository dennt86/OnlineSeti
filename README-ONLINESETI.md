# Onlineseti VPN — Android

Клиент OnlineSeti VPN для Android. Версия приложения — 0.1.2. Перед массовым распространением APK ещё нужно проверить на реальных телефонах, сетях и подписках; локальная сборка предназначена для разработки и проверки.

## Основа и лицензия

- qThroneMobile: https://github.com/ttrroyy/qThroneMobile, commit `46ccf4ea349bfa681afc6bca1c8f035ed7aab955`.
- qThrone core: https://github.com/ttrroyy/qThrone, commit `93e4873c56c2285f647d0146a0df9c088f122910`.
- Лицензия GPL-3.0 и уведомления авторов сохранены. При распространении бинарника необходимо предоставлять соответствующий исходный код и лицензии компонентов.

## Изменения

- Профиль «Россия напрямую» включён по умолчанию: локальная сеть и наборы geoip-ru, geosite-ru, geosite-category-ru, geosite-ru-available-only-inside идут напрямую; остальные назначения через VPN. DNS российских доменов также напрямую.
- Четыре списка включены в APK для первого запуска без загрузки; ядро обновляет их через VPN. Источники — каталог throneproj/routeprofiles и указанные в нём поставщики списков.
- Обновление заменяет только нетронутый профиль Default версии 0.1.0, сохраняя его ID. Пользовательские маршруты не перезаписываются. Списки не гарантируют классификацию всех сервисов; пользовательские полные конфигурации имеют собственную маршрутизацию.

- Отдельный Android application ID `ru.onlineseti.vpn`.
- Синяя тема, логотип и иконка Onlineseti; кнопка перехода в Telegram-бот.
- Импорт `onlineseti://import?url=<URL-encoded HTTPS subscription>` с подтверждением.
- Быстрый импорт допускает только домены openseti.ru и onlineseti.ru и путь `/subscription/<token>`.
- Повторный импорт той же подписки обновляет существующую группу.
- Для нашей подписки создаётся профиль «Автоматически · Onlineseti» вне обновляемой группы. Он выбирается при отсутствии предыдущего выбора.
- Проверка состояния каждые 10 секунд, проверка соединений каждые 60 секунд. Реальное время переключения зависит от сетевых таймаутов.
- Встроенная проверка обновлений и загрузка APK включаются только для release-сборки, подписанной постоянным ключом OnlineSeti; debug-сборки не предлагают устанавливать неподписанное обновление.

## Протоколы и переключение

Сохранены исходные обработчики протоколов и native transports. Это не означает, что каждый протокол проверен в этой сборке. В первую очередь нужно проверить Hysteria2, TUIC и VLESS/XHTTP с нашей подпиской.

Автоматический выбор использует механизм upstream AutoSelector. В upstream есть ограничения для OpenVPN/OpenConnect, Tailscale, extra-core и некоторых пользовательских конфигураций. Не обещать автоматическое переключение для абсолютно всех типов подключений.

## Локальная сборка

На Windows используется WSL Ubuntu, чтобы избежать проблем Android NDK с кириллицей в пути. Рядом с этим каталогом должен находиться `onlineseti-core` указанной версии.

1. Установить в WSL JDK 17, Python 3, unzip, build-essential, pkg-config, git и ca-certificates.
2. Выполнить `bash scripts/prepare_local_linux.sh` (загружает Android SDK/NDK и Go).
3. Выполнить `bash scripts/build_local_linux.sh`.
4. Тестовые APK копируются в `artifacts/`.

Debug APK предназначен для проверки. До выпуска нужны постоянный ключ подписи, тестирование на телефоне и план обновлений. Не включать клиентские токены и секреты серверов в APK или репозиторий.

## Проверка перед выпуском

- Импорт и повторный импорт подписки, её обновление и истечение срока.
- Подключение на Wi-Fi и мобильной сети, смена сети, сон телефона.
- Отказ активного сервера и переход на доступный без ручного выбора.
- Проверка DNS и маршрутизации через туннель, корректное отключение VPN.
- Проверка native transports на поддерживаемых ABI.
- Установка и обновление приложения, корректность ссылки из Telegram.
